Warehouse Management System

PILOT Extension for Comprehensive Warehouse Operations with Zebra RFID Integration

Version: 1.0.0
Extension Name: warehouse-management
Target Platform: PILOT Fleet Management System
Framework: Ext JS 7.7+ Integration

Overview

The Warehouse Management System extension provides comprehensive warehouse operations management integrated with Zebra RFID technology. This extension enables real-time inventory tracking, automated workflows, and seamless integration with warehouse hardware including RFID readers and barcode scanners.

Technical Architecture

Frontend Architecture

  • Technology: PILOT Extension using Ext JS 7.7+
  • Pattern: Navigation tab + Main panel (mapframe)
  • Integration: Runs inside existing PILOT application
  • Entry Point: Module.js class-based initialization
  • UI Framework: Ext JS components with custom warehouse workflows

Backend Integration

  • API Architecture: RESTful AWS Lambda functions
  • Database: PostgreSQL for data persistence
  • Communication: Ext.Ajax.request() for API calls
  • Real-time Updates: Polling-based data refresh

RFID Integration

Supported Hardware

Device Type Model Functionality
Fixed RFID Reader Zebra FX9600 Gate monitoring, bulk scanning
Handheld RFID Zebra MC3330R Item-level scanning, validation
Touch Computer Zebra TC27 Barcode scanning, data entry

RFID Technical Specifications

  • Frequency: 860-960 MHz (UHF)
  • Read Range: Up to 15 meters
  • Tag Support: EPC Gen 2, ISO 18000-6C
  • Integration: Zebra EMDK (Enterprise Mobility Development Kit)
  • Anti-collision: Multiple tag reading capability

API Integration

Core Endpoints

GET /api/warehouse/dashboard

Retrieves real-time warehouse metrics, inventory status, and active alerts

POST /api/warehouse/inbound

Creates new inbound delivery with item details and expected quantities

POST /api/warehouse/rfid/scan

Processes RFID scan data with EPC validation and item mapping

GET /api/warehouse/putaway

Retrieves pending put away tasks and transfer orders

POST /api/warehouse/picking

Creates picking tasks for outbound deliveries

Data Sources

  • Inventory Data: Real-time stock levels, locations, and allocations
  • Transaction History: Complete audit trail of warehouse operations
  • RFID Scans: Tag detection events with timestamp and location
  • Alert System: Unauthorized movements and system notifications

Workflow Operations

Good Receive Workflow

  1. Create inbound delivery with expected items
  2. Generate EPC codes for incoming items
  3. Physical receipt with RFID/barcode scanning
  4. System validation and inventory update
  5. Completion confirmation and reporting

Put Away Workflow

  1. Create transfer order from inbound to storage
  2. Assign operator and target locations
  3. RFID validation at source location
  4. Scan destination bin barcode
  5. Confirm put away completion

Picking Workflow

  1. Create picking task for outbound delivery
  2. Generate optimized picking list
  3. RFID scanning at pick locations
  4. Validate items at exit gate
  5. Complete outbound shipment

Installation & Setup

Prerequisites

  • PILOT Fleet Management System (compatible version)
  • Zebra EMDK installation for RFID support
  • Warehouse Management API backend deployment
  • PostgreSQL database with warehouse schema

Installation Steps

  1. Deploy extension files to PILOT extensions directory
  2. Register extension in PILOT admin console
  3. Configure API endpoints and database connections
  4. Set up RFID hardware and network connectivity
  5. Perform initial data setup (items, locations, users)
  6. Activate extension for target accounts/contracts
Important: Ensure all RFID hardware is properly configured and network accessible before activating the extension. Test RFID connectivity using Zebra's diagnostic tools.

Troubleshooting

Common Issues

Issue Possible Cause Solution
RFID reader not connecting Network connectivity, EMDK not installed Check network settings, reinstall EMDK
API calls failing Backend service down, wrong endpoint Verify API service status and configuration
Dashboard not loading Database connection issue Check database connectivity and permissions
Tags not reading Tag damage, antenna positioning Check tag integrity and reader positioning
