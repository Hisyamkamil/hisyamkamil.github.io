Command Extension

Purpose

This PILOT extension automatically sends periodic API requests to configure command communication settings. The extension runs silently in the background without any user interface, sending configuration data to the PILOT backend every second.

Functionality

  • Automatic Initialization: Starts immediately when the extension is loaded
  • Periodic API Calls: Sends requests to /ax/commands/save.php every 1 second
  • Timestamp Generation: Each request includes a unique timestamp identifier
  • Background Operation: No user interface - runs transparently
  • Error Handling: Logs success/failure of API calls to console

Data Sources

API Endpoint

URL: /ax/commands/save.php

Method: POST

Content-Type: application/x-www-form-urlencoded

Payload Structure

  • config: JSON string containing Modbus zone and command configuration
  • agents: Fixed agent ID (289493)
  • name: Current timestamp in ISO 8601 format

Configuration

Default Command Configuration

  • Zone rule: 0 (disabled)
  • Active time: 00:00 to 23:59 (24/7)
  • Timezone: -7 (UTC-7)
  • Active days: Monday through Sunday (w1-w7: all "on")
  • Command type: GPRS
  • SMS command: "010403E80001B1BA" (hex format)
  • Duration: 1 minute after trigger
Note: This extension operates automatically and continuously. Monitor console logs for API call status. The extension will attempt to reconnect and continue sending requests even if individual calls fail.

Technical Details

  • Extension Type: Background service (no UI components)
  • PILOT Integration: Extends Ext.Component, follows PILOT Extension specifications
  • Frequency: 1 request per second (1000ms interval)
  • Resource Usage: Minimal - only HTTP requests and basic timer functionality

Installation

  1. Host the extension files (Module.js and doc folder)
  2. Register the extension in PILOT admin with the base URL
  3. Activate the extension for the desired contract/account
  4. Monitor console logs to verify operation
